Reference

API Reference

A quick reference of the symbols exported from the @motifx/core package.

This section is a quick reference of the main symbols exported from the @motifx/core package. Every row links to the related detailed section.

Application

Symbol Kind Description
Application class The application instance. The global instance is reached through Application.main, and from a component through context (this.context in a class and in Options, the context of the root component in a function component).
Application.CreateBuilder() static Produces an ApplicationBuilder.
ApplicationBuilder class Carries the services collection; produces an Application with build().
app.run(host, root?) method Mounts the application on a DOM element. If host is a comment or text node, the application is placed right in front of that node and the node stays in place; if the node has no parent element, MJX416 is thrown. A disposed application starts again with run(): Application.main is filled again, services are created again on first request (those with startup: true right away), a new module is set up with the router configuration, the useTransitions mode is applied again, a layer read in the meantime is moved after the host, and dispose() works again. If a new application was set up in the meantime, MJX405 is thrown.
app.useRouter(opts) method Defines routing.
app.restartRouter(uri?) method Sets up the router from scratch and restarts it from the root (/) or from the given address: if a new useRouter configuration was given while running, it uses that, otherwise the current configuration. The route list, the keepAlive cache and the stack are reset; the page on screen leaves like a leaving page and the new page is built (onRouterChanged runs with initial: true); the address is written over the current history entry. Returns the result of the startup navigation. Has no effect before run.
app.connectDocument(doc) method Connects another document of the same origin (a window.open window or an <iframe>) to the application: the router's link catcher and the stack's scroll listeners are set up on that document too. It is counted; the function it returns undoes the connection, which also comes undone on its own when the document's window gets pagehide, and app.dispose() undoes all of them. It has no effect for the page's own document. A value that is not a document, has no window or cannot be accessed throws MJX417.
app.windows property The window manager (WindowManager): open(component, options) opens the component in a new window, or always on top with kind: "pip", and returns an AppWindow handle; create, attach, of, supports, closeAll; list is reactive; the events are window-opened / window-closed. See: Windows.
app.layer property The page layer (Component): the first time it is read, it puts a plain <div> at the end of <body>, after the host element, and returns the component that wraps it (if the host is <body> itself or contains the layer, the layer stays at the end of the host and the shell content goes in front of it); it writes no styles or attributes, can be read before run() too (if there is no <body> yet, it is placed when the document loads; if the element has been taken out of the page, it is put back at the end of the body the first time content asks for a place, or in run()), and app.dispose() disposes it together with its contents and removes the element. See: Page layer.
app.layerOf(target?, ...components) method Returns the layer of the target's (a component or a DOM node) document: the host if it is an app.windows window, otherwise, or if there is no target, app.layer; it adds the given components there with controls.add. A first component that has no parent and whose element is in no document is content, not a target; a root without a parent whose element sits in a document is a target. A target that is neither a component nor a node throws MJX424.
app.navigate(uri, options?) / app.navigateByName(name, params?, options?) method Navigation in code; the options are passed on to the router (NavigationOptions). Returns the result of the navigation (e.g. { ok: false, cancelled: true, reason: 'guard' } when a guard cancels it).
app.router.navigate(uri, options?) method Navigation with options: { replace?, state?, force?, scroll? } (NavigationOptions).
app.router property A single object for the whole application (Router); reactive, read-only route fields: params, route, uri, ok, meta, extend, fullPath, aliasOf, chain, direction, state, stack (only while stack is on). See: Navigation and Route State.
app.useGuard(guard) / app.use(mw) method A navigation guard / middleware. For after a navigation, app.onRouterChanged(fn).
app.on/fire/off method The application event bus. on returns an unsubscribe function.
app.onRouterChanged(fn) method Runs on every navigation (startup and 404 included) with { uri, params, meta, route, ok, initial, redirectedFrom?, direction, state }.
app.onLifecycle(fn) method The application lifecycle: { state, visible, online }; state: 'visible' \| 'hidden' \| 'frozen' \| 'resumed' \| 'restored' \| 'online' \| 'offline'. Returns an unsubscribe function. See: Lifecycle.
app.isVisible / app.isOnline property The current visibility and connectivity state.
app.router.evict(name \| route?) method Disposes the instances in the keepAlive cache (with no argument: all of them).
app.router.resolve(uri) / app.router.href(name, params?) / app.router.routes method / property Matching without navigating (RouteResolution: { chain, result }), the path of a named route, and the route list in definition order (RouteInfo[]). See: The Route Table.
app.router.scrollPositions() / app.router.restoreScrollPositions(positions) / app.router.saveScrollPositions(fn) method The scroll memory's positions ({ "/notes": 1200 }, including that of the page on screen); adds the given positions to the memory (before run() too); calls fn(positions) every time saving is needed (when leaving a page, on pagehide, when the page is hidden, on app.dispose()) and returns a function that removes the subscription. Empty / no effect while scrollMemory is off. See: Scroll memory.
app.useDevelopment(b) / app.useLogging(b) / app.useReactiveMonitor(o) method Development configuration.
app.dispose() method → Promise<void> Sets app.state to 'disposing'; disposes the router and the lifecycle listeners, and rolls back the address according to the router's mode (history: /; hash/file: only # is removed; shell and no router: not touched) (these happen synchronously). Then it disposes the route pages (with their leave animations) and the shell that run() set up (its RouterView and the root given to run() included), disposes the service provider last, and empties Application.main. While the tree is torn down, every component and the code running during animations see the same services and context. The host element stays on the page, empty. The promise resolves when everything, the services' async disposes included, is finished: await app.dispose(); a second call in the same life returns the same promise; in an application restarted with run(), dispose() works again; called again on a finished application, it disposes the layer, windows, document connections and recreated services set up since then, and does not touch the address or the transition mode; a call that arrives while this is in progress gets the same promise too.
app.state property → ApplicationState 'initializing' (set up), 'running' (run() was called), 'disposing' (dispose() is in progress), 'disposed' (can be restarted with run()). While an application is 'disposing', a new Application.CreateBuilder() can be set up; the pages being torn down keep seeing their own application's services.
useApplication() fn { application, services, router, windows, layer, layerOf, attach }.
useNavigation() fn The same object as app.router (Router).

See: Getting Started, Introduction to Routing.

Components

Symbol Kind Description
Component class The concrete component class. super('div') or super().
ComponentBase class The base of all components.
ComponentMotif class The type of the ComponentBase.motif namespace; the user does not create it with new.
FNComponent(view) fn Wraps a function view in a component.
motifComponent(el, props?) / motifFragment(props?) / motifCompiled(contract) / motifReport(error) fn The calls in the code the compiler produces (_mc, _mf, _mv, _mr); motifCompiled prints an MJX121 warning in development mode if the compiler contract does not match; motifReport reports, as MJX208, an error caught in an expression the compiler wrapped in try/catch (a member call in child position, the left side of ??/||, the condition of &&), and the expression's return value does not change.
motifOptions(object) fn Returns the Options object as it is; on the type side it makes this in the methods the component (ComponentBase & object): this.class, this.motif and this.props compile in strict mode and the editor completes them. Its type is MotifOptions<T>; the el key is required (undefined/null is a fragment).
Frame class A fragment container that holds/swaps a single piece of dynamic content: navigate(page, keepOldControl?) disposes the previous content and places the new one (it takes an array too), navigateLazy(() => import(...), options?) loads with Lazy, flush() disposes the content, current is the content shown, and isBusy tells whether a navigation is in progress. {() => expression} children and when/ternary/switchCase branches are built on top of it. See: Frame.
ContentBody / ContentBlock class A multi-part body: <ContentBody name="x"/> is the body and <ContentBlock target="x">…</ContentBlock> is a part; several blocks pile up in the same body, and when a block is disposed it removes only its own parts. See: ContentBody and ContentBlock.
Transport / TransportTo class Showing a component's content in a named slot outside its tree (e.g. moving page commands into the layout header). See: Transport and TransportTo.
Transporter class Moving in code: Transporter.transport(child, newParent, { index?, keepState?, owner? }), transportMany(children, newParent, options?). See: Transport and TransportTo.
FragmentNode class A component rooted in a fragment (a comment node); motifFragment() and <>…</> produce this. childs and props.nodes are added to the content.
ControlCollection class The type of component.controls; not created with new.
Lazy({ caller, options? }) fn Lazy content through a dynamic import (<Lazy caller={() => import('./X')} />; LazyOptions: Loaderview, Placeholderview, Fallbackview, minDelayMs, timeoutMs, signal, onError, mapResult, retry, onRetry). See: Lazy.
Virtualization<T> class A virtually scrolled list.

Attributes named after methods focus, blur, click, select, scrollTo/scrollBy/scrollIntoView, show, showModal, close, showPopover, hidePopover, togglePopover, requestSubmit, checkValidity, reportValidity, showPicker, load, setSelectionRange, setRangeText, setPointerCapture, releasePointerCapture, fastSeek … call the element's method of the same name, and no attribute is written; if a getter is given, it is called again on every change. show/showModal/showPopover open with true and close with false (close()/hidePopover()); togglePopover passes the boolean on; methods such as close, requestSubmit and load are called on a truthy value; methods with arguments such as setSelectionRange take the value as their argument (an array → an argument list).
