Error and Warning Codes

Every MJX code MotifJS produces; compiler codes, thrown and reported errors, development warnings, their console messages and what they mean.

Every message the framework and the compiler produce carries an MJX code and appears in the console in the form [motifjs] MJX302: Named route 'note' was not found.. The message texts are in English and may change; in your code, branch on the code, not on the message. How errors are thrown, reported and listened to is on the Error Handling page.

Kind What happens
thrown Returns to the caller as a MotifError; caught with try/catch or .catch.
reported Written to the console with errorHandler.report (app.useLogging(false) turns it off) and goes to the errorHandler.addListener listeners; the original error is in cause. Works in production too.
warning Written to the console and the DevTools warning list only in development mode (app.useDevelopment(true)).
value The error comes back as a value or is given to a callback; it is neither thrown nor reported.
Lazy error Given to onError as a Lazy loading error.
compile error / warning Produced by @motifx/compiler during compilation; an error stops the build, and a warning is written to the terminal.
motif-lint A finding of the type-aware checking tool.

The places shown with ‹…› in the message column are filled with the value at run time.
